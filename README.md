# 智创2606 · 班级日志

原生 HTML、CSS、JavaScript 静态网站，无需安装依赖。适配电脑与手机，含校园插画、日志分类和搜索、照片墙、日志详情、照片放大、日志编辑、照片压缩、本机保存和导入导出。

## 查看

双击 index.html 或使用静态服务器。网站不依赖第三方字体、图片或 CDN。

## 发布到 GitHub Pages

1. 新建仓库（例如 `zhichuang2606`），上传本目录中的文件，确保 index.html 在仓库根目录。
2. 打开仓库 Settings → Pages，选择 Deploy from a branch，分支 main，目录 / (root)，保存。
3. 等待 GitHub 完成部署，通过 Pages 提供的网址访问。

## 添加班级内容

1. 点击「写一篇记录」，填写内容、日期、分类，选择最多 6 张照片。
2. 保存后可在当前浏览器中预览。照片会压缩为最长边 1440 像素的 JPEG。
3. 页面底部「内容管理」→「导出发布文件」，保存 content.js。
4. 上传到仓库根目录，替换原 content.js，提交。GitHub Pages 会更新。
5. 换电脑时可以导入 content.js 继续编辑。

静态网站没有共享上传服务器或账号后台；本机草稿只有当前浏览器可见，不会自动同步到 GitHub。任何访客都能在自己的浏览器写草稿，但只有仓库维护者能发布共享内容。浏览器存储有容量限制，请及时导出备份。初版使用内嵌照片，适合少量记录；照片较多时建议后续改为独立图片目录或对象存储。

已发布日志可以再次导入成为本机可编辑记录；移除本机草稿不会删除已发布内容。删除已发布记录可直接编辑 content.js 的 entries 数组。

文件说明：index.html 页面结构；style.css 视觉样式；app.js 交互；content.js 日志及照片数据；.nojekyll 禁用 Jekyll 处理。
